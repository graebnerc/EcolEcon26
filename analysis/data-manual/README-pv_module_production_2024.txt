What the article gives, and how the file is built from it:
  · world production 728 GW; China 86.4 %  → China = 0.864 × 728 = 629 GW
  · India 24, USA 23, Vietnam ~20, Thailand ~10, Malaysia ~7 GW (as stated)
  · Rest of world = 728 − 629 − 84 = 15 GW (residual, not stated in the source)
